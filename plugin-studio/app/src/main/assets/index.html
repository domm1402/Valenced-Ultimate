6. Beginner help and tips

What is compiling?

TypeScript is the language you write. Valenced plugins run JavaScript, so compiling converts your TypeScript into JavaScript.

How do I start?

1. Pick Hello world. 2. Change the message. 3. Tap Compile. 4. Read any errors shown. 5. Export your ZIP.

Common errors

Missing } means a closing brace is missing. Unterminated string means you forgot a quote. Cannot find module usually means an imported package is not installed or supported by the build environment.

Safety: Plugins can run code inside your Discord client. Only install code you understand and trust. Never paste your Discord password or account token into a plugin.
