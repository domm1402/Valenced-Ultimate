# Valenced Ultimate

A Revenge/Vendetta-family plugin with a unified settings panel for client-side cosmetic customizations.

## Install

After GitHub Pages is enabled for this repository (deploy the `gh-pages` branch), add this folder URL in Revenge → Plugins → +:

`https://tiktoknotificationtroll-wq.github.io/Valenced-Ultimate/valenced-ultimate/`

## Included
- Unified Valenced Ultimate settings panel
- Local badge/profile showcase preview
- Cosmetic emoji and app-icon preference toggles (client-side only)
- Custom Rich Presence text preview/settings (does not publish Discord RPC by itself)

**Important:** This cannot grant Nitro, unlock Discord's server-side emoji permissions, issue official badges, or change account/server state. The settings are local preferences and previews.

## Build
GitHub Actions builds each plugin folder from `plugins/*/manifest.json` and publishes compiled plugin folders to the `gh-pages` branch.
